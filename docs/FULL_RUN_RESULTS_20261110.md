## 3. 训练协议与实际耗时

两次训练分别从同一 Base 初始化；四卡、ZeRO-2、BF16/SDPA、microbatch 1、梯度累积 12、有效 batch 48、seed 42、1 epoch。优化器 AdamW，学习率 `4e-5`，warmup ratio `0.03`，cosine scheduler。沿用原版 padding-only label collator 的监督范围；loss 不是独立答案准确率。

| 项目 | Instruct | AoTD |
|---|---:|---:|
| 原始训练记录 | 133,654 | 138,053 |
| 训练视图补齐记录 | 26 | 43 |
| 实际训练视图长度 | 133,680 | 138,096 |
| 完成 optimizer steps | 2,785 | 2,877 |

| 最终完整断点 | checkpoint-2785 | checkpoint-2877 |

补齐只重复种子打乱后视图的少量真实记录，使长度整除 batch；原始 JSON 不修改。这保证固定库版本下 epoch 尾部不被丢弃。

两轮训练顺序执行，训练计时合计 **17.17 小时**。四组评测并行，各模型计时约 **3,570–3,576 秒（59.5–59.6 分钟，含模型加载）**，评测阶段日志约 3,601 秒；不能把四份评测时间相加当作实际墙钟时间。这些数值不包括前期下载、制数、调试和等待，不能称为整个项目耗时。
